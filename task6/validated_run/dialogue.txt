===== SCIENTIST =====
## Scientific plan

### 1. Physical reference equation

The Silverbox Duffing form is

\[
\ddot y+a\dot y+by+cy^3=gu,
\]

or, with \(v=\dot y\),

\[
\dot y=v,\qquad
\dot v=-av-by-cy^3+gu.
\]

The proposed model does not impose this polynomial form: a neural network learns the acceleration term \(a_\theta(y,v,u)\).

### 2. Neural state-space model and scaling

Use the centered excerpt signals exactly as specified. For numerically convenient inputs and states, scale using **training data only**:

- \(s_y=\operatorname{RMS}(y_{0:3072})\)
- \(s_u=\operatorname{RMS}(u_{0:3072})\)
- Set a characteristic time \(\tau=0.05\) s, and \(s_v=s_y/\tau\), \(s_a=s_y/\tau^2\).

Define \(Y=y/s_y\), \(W=v/s_v\), and \(U=u/s_u\). The network takes \([Y,W,U]\) and returns a dimensionless acceleration \(q_\theta\), so the physical neural acceleration is \(a_\theta=s_aq_\theta\). The normalized ODE to integrate is

\[
\dot Y=W/\tau,\qquad
\dot W=q_\theta(Y,W,U)/\tau.
\]

This is equivalent to \(\dot y=v,\ \dot v=a_\theta(y,v,u)\).

Use a fully connected MLP with **3 inputs, 3 hidden layers of width 64, tanh activations, and one linear output**. Initialize hidden layers with Xavier initialization. Tanh is smooth, which is appropriate for an acceleration field integrated by RK4.

### 3. Data preprocessing and split

1. Load V1 as \(u\) and V2 as \(y\) from `SNLS80mV.mat`, checking channel orientation before extracting.
2. Extract exactly Python slice `[42650:46746]` from both channels (4096 samples).
3. Subtract each channel’s mean computed over that entire 4096-sample excerpt, as required.
4. Use samples `0:3072` as training and `3072:4096` as test. Do not fit additional centering or scaling parameters on the test data.
5. Set \(dt=1/610.35\) s.

### 4. RK4 integration

Integrate the normalized state \(z=[Y,W]\) using classical RK4 with the fixed step \(dt\). Treat the measured input as zero-order held over each sample interval: all four RK4 evaluations for the interval from sample \(k\) to \(k+1\) use \(U_k\). The resulting state supplies the prediction at sample \(k+1\).

### 5. Training procedure and hyperparameters

Train from short **free-running rollouts**, not one-step acceleration or output prediction with teacher forcing:

- Sample contiguous windows entirely within the 3072 training samples.
- Initialize each window with its measured \(y\) and a finite-difference velocity estimated from training outputs. For interior samples use a centered difference; keep every subsequent state in that window model-generated.
- Drive the window with its measured inputs and minimize mean squared error between predicted and measured normalized \(Y\) over the rollout. Exclude the fixed initial output from the loss if desired.
- Primary settings: Adam, learning rate \(10^{-3}\), batch size 16, 12,000 updates, rollout length curriculum of 64, then 128, then 256 samples, global gradient clipping at 1.0, and AdamW weight decay \(10^{-5}\). Reduce the learning rate to \(3\times10^{-4}\) if training becomes unstable or stalls.
- Use only training data for optimization and any model selection. Reasonable alternatives to try are width 128, two rather than three hidden layers, and rollout lengths of 128 or 512. Do not select settings using test RMSE.

### 6. Exact final free-run evaluation

Once the architecture and weights are fixed, perform **one rollout over the full excerpt**:

1. Initialize \(y_0\) from the first measured, centered output.
2. Initialize \(v_0=(y_1-y_0)/dt\), a forward finite difference at the first sample.
3. Set \(\hat y_0=y_0\), then integrate through all 4095 intervals using measured \(u_k\). Do not reset the state at sample 3072.
4. After initialization, never read measured \(y\) to update or correct the state—including anywhere in the test segment. Test outputs are used only for scoring and plotting.
5. Compute training RMSE over indices `0:3072` and test RMSE over indices `3072:4096`:
   \[
   \mathrm{RMSE}=\sqrt{\operatorname{mean}\big((\hat y-y)^2\big)}.
   \]
   In particular, the test RMSE uses exactly 1024 samples and is in centered output-voltage units.
6. Save a plot of measured and predicted output for test indices `3072:4096`, with time relative to the start of test, to a file such as `silverbox_test_free_run.png`. Report the actual RMSEs only after they have been computed.

### 7. Numbered implementation plan

5. Implement one RK4 step using the same \(U_k\) at all four stages.
6. Implement differentiable rollout windows. Initialize each from training measurements and a finite-difference velocity, but use no measured-output feedback within the rollout.
